# Guia do Usuário — Cliente

## Acesso

URL: `/login`  
E-mail: `cliente@lymity.local` ou `cliente2@lymity.local`  
Senha: `password`

## Dashboard do Cliente

URL: `/client/dashboard`

Exibe:
- Posts recentes para sua marca
- Aprovações pendentes de sua ação
- Arquivos disponíveis
- Atalhos rápidos para as seções principais

## Minhas Aprovações

**Menu:** Aprovações  
**URL:** `/client/approvals`

Esta é a seção mais importante para o cliente. Aqui você pode:

1. Ver todos os itens aguardando sua aprovação
2. Visualizar o conteúdo completo (post, campanha, proposta, etc.)
3. Aprovar — o item será agendado/executado
4. Rejeitar — com comentário opcional explicando a razão

**Importante:** Nenhum conteúdo é publicado ou campanha ativada sem sua aprovação.

## Posts de Social Media

**Menu:** Social Media  
**URL:** `/client/social-posts`

- Visualize todos os posts criados para sua conta
- Veja o status de cada post (rascunho, aguardando aprovação, agendado, publicado)
- Não é possível editar posts diretamente — solicite alterações à agência

## Arquivos

**Menu:** Arquivos  
**URL:** `/client/files`

- Visualize e baixe arquivos enviados pela agência para sua conta
- Faça upload de materiais para a agência (logos, fotos, briefings)
- Arquivos são organizados por pastas

**Segurança:** Você só visualiza arquivos da sua conta. Nunca há acesso a dados de outros clientes.

## Perfil / Configurações

- Altere sua senha em `/client/profile`
- Para alterar dados da empresa, contate o administrador da agência

## Suporte

Em caso de dúvidas, contate sua agência responsável.  
Não compartilhe suas credenciais de acesso.
